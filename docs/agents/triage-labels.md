# Triage labels

Use these exact labels for the five triage roles.
The role names and GitHub label names are identical.
If the vocabulary changes, update this table.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified for agent implementation. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The project will not act on the issue. |
